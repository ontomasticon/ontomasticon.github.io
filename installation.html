Installing Ontomasticon

Download Ontomasticon

Download the latest release from https://github.com/ontomasticon/ontomasticon/releases and unzip into appropriate directory on your web server.

Web server settings

Every address that isn't a file, such as a stylesheet or image, must be passed to index.php, and the code and settings directories must not be served.

  • Apache: the .htaccess file included with Ontomasticon does this. It needs mod_rewrite, and AllowOverride All (or FileInfo) for the directory. The same rules can go in the virtual host configuration instead.
  • nginx: nginx.conf.example is an example server block to adapt.

index.php also makes robots.txt, sitemap.xml and favicon.ico, so don't put files with those names at the top of the installation, as the web server would send them instead (see Pages for search engines).

After replacing the code with a new version, run the database update.

Connect to MySQL

In the settings directory copy db.php.default to db.php and enter your MySQL or MariaDB settings.

Run the install script

In your web browser navigate to [base_url]/inst/install.php to run the install script. The installer sets base_url to the address it was run from. Log in with the account admin and the password password, and you will be asked to choose a new password. Then delete the inst directory.

Installing in a subdirectory

Ontomasticon can be installed in a subdirectory of a website, such as example.org/glossary/. The base_url setting (on the site configuration page, and set by the installer) must include the subdirectory, for example example.org/glossary/: the site's links, and the URIs of its vocabularies and terms, start with it.

  • Apache: the included .htaccess works in a subdirectory. If the site is reached through an Alias rather than a directory under the document root, uncomment the RewriteBase line in .htaccess and give the subdirectory.
  • nginx: add the subdirectory to the start of each location in nginx.conf.example, and to index.php in try_files, as described in the comments at the top of that file.

Sites in different subdirectories of the same domain have separate logins.

Several sites in one database

More than one Ontomasticon site can keep its tables in the same database, if each site's tables have a different prefix. Set the prefix in settings/db.php before running the installer, using only letters A to Z, digits and underscores, for example:

$table_prefix = "glossary_";

The site's tables are then named glossary_config, glossary_terms and so on. Changing the prefix later points the site at a different set of tables, so to change it, rename the tables too.

Debug mode

To enable PHP debugging set mode to 'debug' in the config table of the database.
